## 本轮检查结果

当前源码、许可证、依赖清单及公开文档不包含本机个人目录或账号字面值。示例主目录已统一为 `/path/to/home`。README 主界面截图使用临时演示目录；未展示个人主目录面包屑。第三方作者原始版权和联系方式保留，不作为本机用户信息删除。

`.gitignore` 已覆盖本机 SwiftPM/Xcode 状态、AI 工具目录、签名密钥/证书、环境凭据、应用及安装包、日志、临时备份。thirdparty 仅发布清单和说明，依赖源码与构建结果继续忽略；LICENSE 和 LICENSES 必须保留。

历史测试回滚归档仍含旧遥测配置，作为本地材料保留，并从 Git 候选文件和发布快照中排除。相关报告中的本地证据链接不会成为公开包的附件，不将日志排除后的公开报告宣称为完整的原始证据包。

## 检查与导出

在项目根目录执行，无需第三方 Python 包：

```bash
python3 scripts/check-publication.py
python3 scripts/check-publication.py --export .build/macMTP-source-release.tar.gz
```

检查器只报告匹配类型和文件，不输出疑似凭据内容；扫描 Git 已跟踪及未被忽略的现有文件，也递归检查其中的 tar 附件、文件名、符号链接和归档所有者元数据。它还检查私有文件忽略规则以及应保留的协议/清单是否被误忽略。已跟踪而后又命中忽略规则的现有文件会使检查失败：`.gitignore` 不会自动取消已有跟踪。

导出前必须检查通过。导出的源码归档逐项按字节复核，清除 owner 用户名/组名与时间元数据，且不包含 `.git`、忽略目录、依赖源码、构建产物和历史回滚附件。文件已存在时脚本拒绝覆盖。

这些检查针对明确的字面值和常见凭据特征，不替代人工审查新增内容、图片或源码变更。脚本不扫描或改写已经排除的私有材料、历史提交对象及旧 DMG。

## Git 历史与发布方式

本轮审计发现现有 45 条历史提交的作者或提交者元数据匹配本机账号。工作区文件脱敏不改变历史身份，也不改变已有远端内容。当前仅准备本地源码快照，没有提交、推送、创建公开仓库或改写历史。

如需不携带这些历史身份，可使用通过检查的源码归档初始化新的公开仓库，并由发布者选择公开的提交姓名及邮箱。不要将原仓库的 `.git` 目录复制过去。若决定保留原历史，则需单独处理和审查历史身份及历史文件内容，本轮不将它标记为已脱敏。

## 交付前验证

```bash
./scripts/download.sh --offline
bash Tests/scripts/test-download.sh
swift test
git diff --check
python3 scripts/check-publication.py
```

未下载依赖的新环境先运行 `./scripts/download.sh` 与 `./scripts/build-runtime.sh`。安装包应使用最新源码重新构建，检查签名、对应架构和随包许可证；既有 DMG 不因文档检查而自动更新。
