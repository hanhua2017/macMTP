## 公开文档约定

项目位置使用 `/path/to/MacMTP` 等通用示例；操作指南优先使用 `$PROJECT_ROOT`、`$PWD` 或项目相对路径。用户主目录使用 `/path/to/home`，账号标识使用 `local-user`。这些占位内容需在复现命令时替换为实际工作环境。

历史日志、命令输出和归档已经是脱敏后的公开副本，不再声称是未经处理的原始逐字记录。脱敏没有重新执行或改变历史测试结论。

两个公开源码归档的内容变化后，已同步重算 `change-manifest.json` 的对应文件哈希、重建补丁，并更新 `final-environment.json` 中的文档归档哈希；应用和 DMG 的历史二进制哈希保持原值。公开回滚脚本只适用于与其脱敏快照匹配的副本，不应直接用于当前持续变更的工作区。

原始记录与本轮回滚材料只保存在本地忽略的 `.build/document-privacy-20261029/`，不作为公开文档提交。发布前还应检查实际 Git 暂存内容，避免误将忽略目录、历史二进制或原始日志加入版本库。

本轮未重写 Git 历史、未修改个人机器的账号/路径，也未重新生成已有 DMG。今后新增文档和截图应沿用上述通用路径约定。
